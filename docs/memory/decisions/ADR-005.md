# ADR-005: Uma falha externa descarta a leitura reutilizada

- **Status:** aceita
- **Decidido por:** os dois autores, em conjunto
- **Regras afetadas:** BR-07, BR-08, BR-22

## Contexto

Entre duas consultas, a última leitura externa válida é reutilizada com a idade informada. Quando a consulta seguinte falha, seria possível continuar servindo esse valor até o fim do intervalo.

## Decisão

Toda falha de consulta ou de validação externa apaga a leitura guardada e a fonte fica indisponível até uma nova consulta bem-sucedida.

## Justificativa

Um valor anterior à falha apresentado como atual é exatamente o tipo de propagação silenciosa que o projeto existe para evitar.

## Consequências

C3 entra em degradado já no ciclo da falha. Em compensação, uma queda ocorrida durante o período de reuso só é percebida na consulta seguinte — com o intervalo de 15 minutos fechado em D5a (BR-05), esse atraso é significativo. A D10 (BR-31) manteve a arquitetura: nos experimentos C3–C5, `external_refresh_ms = 5000` faz a fonte externa ser consultada aproximadamente a cada ciclo.
